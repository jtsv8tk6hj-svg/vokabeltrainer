# Vokabeltrainer

Fünfsprachiger Vokabeltrainer (Deutsch, Englisch, Französisch, Polnisch, Russisch)
mit Beispielsätzen und Karteikartensystem nach dem Prinzip wachsender Abstände.

Läuft vollständig im Browser, ohne Konto und ohne Server. Nach dem ersten Aufruf
auch offline nutzbar; auf dem iPhone über "Teilen -> Zum Home-Bildschirm" als App
installierbar.
